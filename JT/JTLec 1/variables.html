Variables in javascript

We can create variables in 3 ways in javascript

  1. Using let keyword
  2. Using const keyword
  3. Using var keyword

Identifier rules

  1. Identifier can not be start with or use special characters (only '$','_' are allowed)
  2. Identifier can not be start with numbers(but can use number)
  3. Identider can not be same as keyword
  4. Identifier can any character between 'A' to 'Z' and 'a' to 'z'
