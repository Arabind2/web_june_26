Function Expression

When a function is assigned to a variable, it is called a function expression.

Annonymous Function

When a function is defined without a name, it is called an annonymous function.

Except function declaration, in all other ways we can use annonymous function to define a function.

Arrow Function

Arrow function is a new way to define a function in javascript.

()=>{return ;}

ii) (a, b) => a + b;
